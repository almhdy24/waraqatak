# Roadmap

This document contains confirmed future work.

## Rules

Only add an item here when it is an actual project requirement or an explicitly agreed improvement.

Do not convert speculative ideas into requirements.

## Priorities

### P0 — Critical

Security, data loss, crashes, broken core workflows.

### P1 — Important

Core functionality and major usability problems.

### P2 — Improvement

UX, maintainability, performance, and non-critical enhancements.

### P3 — Optional

Nice-to-have features.

## Format

Use:

- [ ] Task
- [ ] Task

Add a short note when the task requires architectural or database changes.
